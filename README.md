# SplitPay - Bill Splitting App (Backend Only)

SplitPay is a backend-only application built with Node.js, Express, and Sequelize that simplifies group expense tracking and bill splitting.

## Features

- User Authentication (Signup, Login)
- Group creation & management
- Add members to a group
- Create and share bills
- Settle bills
- JWT-based authentication
- MySQL database support

## Tech Stack

- Node.js
- Express
- Sequelize ORM
- MySQL
- JWT for authentication
